# BrandAI — AI-Powered Brand Naming Platform

BrandAI is an AI-powered brand naming and brand intelligence platform designed to help users generate, evaluate, refine, and manage brand names.

The platform combines AI-powered name generation, brand intelligence, trademark screening, domain availability checks, favorites, brand kits, subscription plans, admin management, usage metering, and Razorpay payments into a single web application.

---

## 🚀 Features

### AI Brand Name Generation

- AI-powered brand name generation
- Multiple naming inspirations
- Industry and target-market based generation
- Style and naming preferences
- Structured AI responses
- Quality filtering
- Duplicate detection
- Name ranking

### Brand Intelligence

- Name comparison
- Name refinement
- Brand intelligence analysis
- Tagline generation
- Logo generation
- Brand kit generation

### Trademark Screening

- Trademark search integration
- Exact and similar name checking
- Trademark risk/status information
- Provider-based trademark architecture
- Jurisdiction-aware screening
- Legal disclaimer for trademark results

> Trademark screening results are informational and should not be treated as legal advice or trademark clearance.

### Domain Availability

- Domain availability checking
- `.com`
- `.in`
- `.ai`
- `.io`
- `.co`
- RDAP-based availability checking
- Provider-based architecture for future integrations

### User Accounts

- User registration
- Login
- Logout
- JWT authentication
- Access and refresh tokens
- Password hashing with bcrypt
- User profile
- Generation history
- Favorites

### Subscription System

BrandAI supports configurable subscription plans.

Each plan can contain:

- Plan name
- Plan code
- Price
- Currency
- Billing period
- Names per generation
- Monthly generation limit
- Feature limits
- Active/inactive status

Premium feature usage is enforced server-side.
